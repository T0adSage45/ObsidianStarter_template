#binds

## 🧾 Default binds

| **Keybind**              | **Action**                | **Description**                                          |
| -------------------- | --------------------- | ---------------------------------------------------- |
| **Ctrl + B**         | Bold                  | Toggles `**bold**` formatting                        |
| **Ctrl + I**         | Italic                | Toggles `*italic*` formatting                        |
| **Ctrl + O**         | Quick Switcher        | Search + jump to notes                               |
| **Ctrl + P**         | Command Palette       | Open all commands (palette)                          |
| **Ctrl + ,**         | Settings              | Open Obsidian Settings                               |
| **Ctrl + K**         | Insert Link           | Add link `[[page]]` or web link                      |
| **Ctrl + ]**         | Indent                | Indent line or selection                             |
| **Ctrl + [**         | Unindent              | Un-indent line or selection                          |
| **Ctrl + E**         | Toggle Edit/Read Mode | Switch between **Editing View** and **Reading View** |
| **Ctrl + N**         | New Note              | Create new note                                      |
| **Ctrl + Shift + F** | Global Search         | Search across all notes                              |
| **Ctrl + F**         | Search in Note        | Search current file                                  |
| **Ctrl + W**         | Close Tab             | Close current note tab                               |
| **Ctrl + Shift + N** | New Window            | Open new Obsidian window                             |
